# Specs

Permanent functional & technical specs. Promotion pipeline (Spec V7 §7):

- Draft: `docs/temp/draft-plan.md` (gitignored)
- Acceptance: promoted to `docs/specs/<id>-<feature>.md` and committed

Naming: `<NNN>-<feature-slug>.md` (e.g., `001-feature-spec.md`).

This directory is intentionally empty until the first spec is approved.
