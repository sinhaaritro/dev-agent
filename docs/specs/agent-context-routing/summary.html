Plan Mutation Guardrail: If execution of any task fails during Step 6, the agent is strictly forbidden from making unapproved assumptions or modifying files. It must stop execution immediately, inform the user of the failure and its reason, offer possible solutions/alternative designs, and await explicit planning approval before resuming.
