# 003-SPEC: Stop the engine from knowing about docs/README.md

Status: BUILDING | Date: 2026-09-27
Handoff: 2026-09-27

## 1. Goal & Context

The spec-builder engine currently bootstraps and regenerates `docs/README.md`
on every promote/topic/handoff/toc run and carries the `tag-index` subcommand
whose only output is that file. This change removes **every** reference to
`docs/README.md` from the engine and its docs: the script should not know the
file exists. `docs/README.md` itself stays as a plain human-maintained file
(its generated TOC/TAG-INDEX blocks are stripped). `specs/README.md` keeps its
generated TOC. No architectural decisions surface (Lane B).

## 4. Affected Files & Contracts

### [MODIFY] .agents/skills/spec-builder/scripts/promote_spec.py

The TOC/tag-index engine. All landing-README machinery is removed; the script
no longer references `docs/README.md` at all.

- Contract:
  - `_ensure_docs_readmes(root)` bootstraps only `specs/README.md` (via
    `_specs_readme_stub`) when missing.
  - `_refresh_toc_for(root)` and `cmd_toc` target only `specs/README.md`
    (specs-only TOC).
  - `_tag_index`, the `tag-index` argparse subparser, its docstring/help, and
    the module-usage block entry are all removed.
  - `_landing_readme_stub()` is removed. `_build_toc_lines` keeps only the
    `"specs"` section path.
  - No string in the file names `docs/README.md` or the landing README.
  - `cmd_promote` writes the promoted spec as `NNN-SPEC-<slug>.md` (matching
    the engine's own `SPEC_KIND` contract) and `substitute_spec_id` stamps the
    title ID as `NNN-SPEC`, so a freshly promoted spec's title matches its
    filename and can be compiled.

### [MODIFY] docs/README.md

Becomes a plain human-maintained file: generated blocks and engine
self-references are stripped; the human prose is kept.

- Contract:
  - The `## Index` intro + `<!-- TOC:START -->`/`<!-- TOC:END -->` block is
    removed.
  - The `<!-- TAG-INDEX:START -->`/`<!-- TAG-INDEX:END -->` block is removed.
  - The "regenerated by `promote_spec.py toc`" and "governed by
    `promote_spec.py tag-lint`" self-references are reworded to
    human-curated phrasing.
  - The folder table, "Frontmatter conventions" and "Status board" prose is
    kept.

### [MODIFY] .agents/skills/spec-builder/SKILL.md

    generated `## Index` marker block; it does not name `docs/README.md`.
